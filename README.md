# Daffa AI Coder

Demo model AI yang di fine-tune untuk generate kode Python dari deskripsi.

## 📋 Fitur
- Generate kode Python dari deskripsi bahasa natural
- Mendukung berbagai fungsi Python dasar
- Interface user-friendly dengan Gradio

## 🚀 Cara Menggunakan
1. Ketik deskripsi kode yang Anda inginkan
2. Klik "Generate Code"
3. Salin kode yang dihasilkan

## 🛠️ Teknologi
- **Model Base:** T5-small
- **Framework:** Transformers
- **Interface:** Gradio
- **Hosting:** Hugging Face Spaces
